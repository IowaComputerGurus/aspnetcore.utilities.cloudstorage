# Security Policy

## Supported Versions

This project supports current versions for security updates and will update as needed for security-related issues.

| Version | Supported          |
| ------- | ------------------ |
| 8.0.x   | :white_check_mark: |
| < 8.0   | :x:                |

## Reporting a Vulnerability

If you believe you have found a security vulnerability, you may report it privately here via the "Security" tab.  We strive to respond to all security issues within 1 business day and will work with you to get a release updated as soon as possible thereafter. 

Security-related items should NOT be submitted as "Issues" for privacy & security.
